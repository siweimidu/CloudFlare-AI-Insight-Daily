### **今日AI资讯**

1. **WordCraft**：一款使用**纯 Rust** 编写的 Microsoft Word **开源净室重构**实现，在 GitHub 上备受关注。

2. **Anatomy**：一款智能体技能工具，用于创建**精细交互式等距插图**，支持生成带有 WebGL 着色器和 3D 特效的 **SVG 文件**。

3. **GridCraft**：由 ArtCraft 开发，基于**纯 Rust** 编写的开源**净室电子表格应用**，旨在提供 Microsoft Excel 风格的功能。

4. **ARTEX**：百度"agent+”攻防挑战赛冠军项目，是一款先进的**AI 自主渗透测试系统**。

5. **CADCraft**：一款专注于计算机辅助设计与绘图的工具，采用**纯 Rust** 开发，是 AutoCAD 的开源净室替代方案。

6. **nvidia-macos-driver**：为 macOS 15 Sequoia (Intel/OpenCore) 系统提供的开源 **NVIDIA GeForce RTX 显卡 Metal 驱动**。

7. **DeckCraft**：ArtCraft 系列应用之一，是 Microsoft PowerPoint 的**纯 Rust 开源重构版**，支持演示文稿制作。

8. **omdrop-owl**：一款专为**非苹果设备**设计的隔空投送（AirDrop）互操作工具。

9. **SoundCraft**：Avid Pro Tools 的**纯 Rust 开源净室重构**版本，提供专业音频制作功能。

10. **Tendedero**：一款极简的 **macOS 原生截图管理工具**，将截图以"挂在绳上”的视觉方式呈现。

11. **Fsearch**：高效的 **macOS 全盘搜索工具**，支持模糊匹配、容错及基于索引的 grep 搜索，具备极高的检索性能。

12. **DigUp**：基于 Google DeepMind 的 **EmbeddingGemma 2 模型**，支持在设备端本地搜索照片、PDF 及音视频内容。

13. **craft-launcher**：专门为 ArtCraft 系列应用设计的**统一启动器**。

14. **CCBaga**：GitHub 上的近期开源项目，目前相关技术细节尚未提供。

15. **pt-pc**：恐怖游戏《P.T.》的**原生 PC 移植版**，支持用户利用原有 PS4 游戏文件进行运行。

16. **playgta5**：该项目为 **playgta5.com 网站**的开源源代码库。

17. **DeepSeek-Bot**：一套用于 DeepSeek Harness 的**长驻机器人团队**，支持机器人间的通信与自动化群聊协作。

18. **helix-foundry**：一个**本地优先的数据工作空间**，基于 HelixDB 和 DuckDB 构建，支持将企业数据整合进本地本体论模型。

19. **ts-rust**：TypeScript 7 编译器 (tsc) 的一项**实验性 Rust 移植**技术探索。

20. **SolidCraft**：一款基于**纯 Rust** 构建的**参数化 3D CAD 应用**，支持桌面、Web 以及通过 MCP 实现自动化操作。
