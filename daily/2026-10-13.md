## AI洞察日报 2026/10/13

>  `AI 日报` 



### **今日摘要**

```
今日资讯涵盖多款基于纯Rust构建的开源软件及前沿技术。
其中Wordcraft等ArtCraft系列对标办公软件，功能丰富。
此外AI攻防系统、本地化检索及跨平台驱动等创新项目显著。
```



### **今日AI资讯**

1. **Wordcraft**：一款由 **Storytold** 开发的、使用 **纯 Rust** 编写的 Microsoft Word 开源净室重新实现版本，在 GitHub 上斩获 9392 颗星。

2. **Anatomy**：一款创新的代理工具，用于生成带有 **WebGL 着色器**和 3D 效果的精致 **SVG** 插图，适用于创建复杂系统的交互式等距视图。

3. **Gridcraft**：由 ArtCraft 出品的开源净室**电子表格**程序，功能对标 Microsoft Excel，同样采用纯 Rust 编写。

4. **ARTEX**：一款**AI 自主渗透测试系统**，凭借卓越的性能荣获百度"agent+”攻防挑战赛冠军。

5. **Cadcraft**：开源净室 CAD 绘图工具，致力于实现 AutoCAD 风格的强大功能，基于纯 Rust 构建。

6. **nvidia-macos-driver**：为 **macOS 15 Sequoia** 系统提供的 **NVIDIA GeForce RTX** 显卡 Metal 驱动程序，提供免费的开源解决方案。

7. **Deckcraft**：ArtCraft 系列应用之一，是 Microsoft PowerPoint 的纯 Rust 开源净室实现版本。

8. **omdrop-owl**：一款为非苹果设备量身定制的 **隔空投送 (Airdrop)** 功能实现工具。

9. **Soundcraft**：基于纯 Rust 开发的开源净室音频工作站，旨在对标 Avid Pro Tools。

10. **Tendedero**：轻量级 macOS 应用，以"晾衣绳”交互形式在屏幕顶部管理**屏幕截图**，提升工作流视觉体验。

11. **Fsearch**：高效的 macOS 全盘**文件搜索**工具，具备模糊匹配与索引 grep 能力，处理 800 万个文件仅需 1 毫秒。

12. **DigUp**：基于 Google DeepMind 的 **EmbeddingGemma 2** 模型构建，支持在 macOS 本地进行照片、PDF 及代码等深度内容检索。

13. **Craft-launcher**：专门为 Storytold 旗下的 Craft 系列应用程序提供统一的**应用启动器**。

14. **CCBaga**：该项目暂无详细描述，但在开源社区中已积累 1721 颗星。

15. **Pt-pc**：恐怖游戏《P.T.》的**原生 PC 移植版**，支持用户利用个人 PS4 游戏文件进行游玩。

16. **Playgta5**：知名网站 playgta5.com 的**开源源代码**仓库。

17. **DeepSeek-Bot**：基于 **DeepSeek Harness** 的机器人套件，支持群聊功能及机器人间的复杂通信。

18. **Helix-foundry**：基于 **HelixDB** 和 **DuckDB** 的本地优先数据工作区，旨在将公司数据转化为本体并实现私有化存储。

19. **Solidcraft**：一款纯 Rust 构建的参数化 **3D CAD** 应用，支持桌面、Web 及 **MCP 自动化**流程。

20. **Ts-rust**：一项实验性技术项目，旨在通过 **Rust 语言**对 **TypeScript 7 编译器 (tsc)** 进行重构与移植。
