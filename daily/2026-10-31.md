### **今日AI资讯**

1. **学术研究领域**：研究者探索了**大型语言模型 (LM) 数据归因**的设计空间，引入了 **CATT 基准**以通过虚拟知识进行精准追溯；提出了 **Propose-Filter-Release (PFR)** 机制，通过私有过滤实现**差分隐私**下的稳健数据处理；同时，通过 **Perturb-Select-Vote (PSV)** 程序揭示了"神经丛 (Neural Thickets)”现象无需权重扰动，仅靠输出多样性与筛选即可实现；此外，**SpecSlot** 架构通过角色耦合 Token 化优化了生成式 Transformer 的效率，在保持细节的同时降低了全局计算成本。

2. **AI Agent 与前沿应用**：多智能体协作研究取得新进展，包括用于科学研究的**协作式 AI Agent** 实验实验室，以及针对 Agent 间共谋行为的**事前预警系统**；**VeriCUA** 框架通过代理式探索实现了对计算机使用 Agent (CUA) 的可靠任务验证；在硬件端，多款安卓手机运行 **DeepSeek Harness** 的开源项目（如 `dsh-Go`、`Mika`）受到社区高度关注，显示出本地端侧 AI Agent 的强劲增长势头。

3. **安全性与行业动态**：近期安全领域爆发重大事件，官方 **Claude Code** VS Code 扩展程序在 Cursor 市场中被植入**后门程序**，引发了广泛的安全担忧；与此同时，美国国会议员发起决议反对对大科技公司的 AI 泡沫进行"救助”；行业内对于 AI 成本的担忧导致多家科技巨头股票下挫，关于 AI 是否在造成 **SRE 等岗位技能退化 (deskilling)** 的讨论也在 Hacker News 等社区激起了 400 多条评论的热议。

4. **创意编程与开发工具**：开源社区涌现出极具创意的项目，如将 Doom 游戏机制转化为**图灵完备转换器 (DOOMFORMER)** 的实验；此外，一批专注于**视频生成与剪辑**的工具（如 `MoonReel`、`Kinoloom`）及针对 AI 编程 Agent 的威胁建模框架也相继发布，体现了开发者在模型应用边界探索上的活跃度。
