### **今日AI资讯**

1. **AI 编码工具泄露安全风险**：Claude Code 的"不再询问”功能导致 1,122 个公共 GitHub 文件**泄露密码**，引发业界对编码智能体安全性的高度关注。

2. **微软重组 AI 研发架构**：微软研究部门的 **AI Frontiers 团队**被宣布解散，该变动在 GitHub 及技术社区引发了广泛讨论与深度复盘。

3. **AI 行业估值波动与监管压力**：受 AI 市场回调影响，Anthropic 的 IPO **估值预期**出现大幅下调；同时，民主党针对 SpaceXAI、Meta 和 Apple 启动了**国会调查**。

4. **开源模型与工具进展**：多个创新项目发布，包括 14B 压缩版**视频扩散模型**（Hyperflow-H3-Flash）、Perplexity 的**工作流 AI 智能体**，以及 OpenAI API 新增的**外呼 SIP 通信**功能。

5. **AI 加速科学研究趋势**：AI 正显著提升科研效率，多项重磅研究（如 **Scientist World**、**SwarmEvolve**）展现了 AI 在自动驾驶程序发现、数学计算及自动化实验中的强大潜力。

6. **模型可解释性与安全性研究**：最新论文探讨了通过**稀疏字典学习**理解用户嵌入、机械可解释性对 **AI 安全**的支撑作用，以及利用潜空间交互的**故障检测**技术。

7. **ML 工程与工具生态演进**：GitHub 推出了新的 **Git 存储架构**；社区开源了涵盖 3D 建模库 **Sand3d**、本地视频生成应用 **PromptReel** 及多智能体可视化协议 **MAS-Office** 等多样化工具，赋能开发者构建更先进的 AI 应用。
