### **今日AI资讯**

1. **agentes-chat** 是一个开源、可自托管的 **Slack 替代方案**，支持团队与集成 **Claude、ChatGPT、Gemini 或 Grok** 的 AI 智能体进行协作。该系统配备 **MCP 工具**、专属计算机环境、记忆能力及审批流程，支持多端部署。

2. **ste80-humanizer** 提供了一种人性化工具，作为智能体技能使用，旨在将 AI 生成的内容重写，使其 80% 符合 **ASD-STE100（简化技术英语）** 标准，消除 AI 生成痕迹。

3. **MACaQ** 是一种针对 **GGUF 格式**的模型无关量化方案，通过 **llama.cpp、vLLM 和 PyTorch** 等框架，支持对文本、图像、视频及音频模型进行高效的本地推理与量化。

4. **BookLeme（读了么）** 通过双引擎与可插拔体裁插件，将书籍编译为具备高忠实度的 **Agent Skill（智能体技能）**。

5. **blender-ai-mcp-addon** 为 **Blender** 提供 AI 助手与 **MCP 服务器**支持，实现可视化聊天、场景工具操作、**3D 辅助驾驶**及多智能体工作流协作。

6. **Awesome-AI-for-Astronomy** 汇总了天文学与天体物理学领域高质量的 **AI 研究论文**精选列表。

7. **AI Manus** 是一个通用的 **AI 智能体系统**，专注于在沙箱环境中执行各类工具与操作，社区内存在多个相关实现版本。

8. **actp** 定义了专为智能体设计的通信传输协议，支持 **ACP over HTTP** 模式。

9. **weight-space-programming** 提出了一种无需梯度的权重编辑方法，用于减少 **Qwen3.8-27B** 模型的过度思考，并提供相关评估产物。

10. **Voice-Changer-2026** 利用神经模型和低延迟技术，提供 AI 驱动的实时语音转换与变声功能。

11. **ml4sci** 为研究者提供了交互式机器学习课程与实验，通过浏览器内的 **学习桌面** 完成从基础到实践的训练。

12. **private-doc-scanner** 是一款开源的 **AI 隐私文档扫描仪**，在本地读取文档并将敏感数据存储在专属保险库中。

13. **agent-ide.nvim** 将 **Neovim** 编辑器转化为智能体会话环境，通过缓冲区实现对 Markdown 格式会话的美观处理。

14. **videomd** 引入了一种开放的视频解析格式，通过 **VIDEO.md** 和 **SKILL.md**，支持模型对视频内容进行层级化阅读。

15. **llm-manual-lab** 提供免费教科书《LLM 理论与 AI 实验室实践》，并配套基于 **TypeScript** 的实验室练习。

16. **heartdisease-ml-prediction** 使用 **scikit-learn** 构建，专门用于临床心力衰竭预测的 Python 机器学习流水线。

17. **mixture-of-scars** 提出了 **MoS 静态权重压缩技术** 与 **SCache O(1) 常数级 KV-cache** 方案，优化 LLM 与硬件的协同。

18. **halo** 是一款基于 **TUI** 的智能体团队协作应用，支持智能体间（a2a）自动任务委派，提供类 Lazy Git 的编程体验。

19. **car-use** 实现智能体与车辆的物理连接，通过 **OBD-II 接口** 让 Claude Code 等模型读取并诊断真实车辆。

20. **JJ_ML_DL_BOOK** 汇集了西班牙语的数据科学、机器学习与 **Transformers** 教育资源，包含 Python 与 PyTorch 实践。

21. **herdr-grok-bot** 为 **Grok Bot** 提供社区技能支持，允许用户在 CLI 环境中实时观察与干预智能体。

22. **milletcode** 是一个专注于多智能体编排的开发平台。

23. **flecten** 是一款编程智能体桌面工具，支持在工作的同时进行对话，并将 **IDE** 集成在单一窗口中。

24. **gdg-uam-ml-contest-2026** 提供针对多通道时间序列分类的 **1D CNN 模型**，优化了 ONNX Runtime 和 Numba 的 CPU 推理性能。

25. **mcp-attest** 为 **MCP 服务器**提供授权一致性测试，模拟身份并生成可审计的证据。

26. **koel** 是一个针对癌症突变评分的开放信任检查器，用于评估 **AlphaMissense 和 ESM1b** 在癌基因研究中的证据权重。

27. 论文《Unbundling Multimodal Vision Encoding》研究了多模态模型中**视觉编码器**的设计选择，指出联合训练的视觉能力优于预训练，且无需预融合。

28. 论文《ArchSpace》推出了一个记录、评估与引用 **LLM 架构研究**的平台，旨在通过缩放定律在成本高昂的训练前预测模型表现。

29. 论文《Internalizing Investment Mandates》提出一种**神经符号强化学习**方法，用于在投资组合分配中严格执行规则约束。

30. 论文《AgentSSL》探讨了**半监督学习（SSL）**在智能体中的应用，证明了智能体在标签数据稀缺时能合成优于人类基准的 SSL 程序。

31. 论文《Learning When Diffusion Language Models Should Regenerate》提出了 **DiVR 验证器**，通过预测生成准确性来动态决策模型重写时机。

32. 论文《CoReMem》引入了成本内化记忆框架，优化了编码智能体在**连续任务执行**中的记忆写入与读取效率。

33. 论文《Linking Rapid Learning to Compositional Structure》发现**元学习**能组织参数空间，使神经网络通过参数向量的加减法实现功能组合。

34. 论文《Sketching Language Models for Context Attribution》提出了一种高效的**上下文归因算法**，利用草图技术显著降低模型计算成本。

35. 论文《Classical Energies Learn to Reason 1,000x Faster than Looped Models》提出 **CRAM 架构**，利用经典能量函数解决复杂逻辑问题，速度比循环模型快 1000 倍。

36. 论文《Quantifying structural stability of transparent models》定义了**函数透明度**，并提出距离度量标准，以量化保险精算模型更新后的结构稳定性。

37. 论文《Towards a Theory of Learnability via Debate》从在线学习的角度分析了**辩论式训练协议**，指出了辩论在学习复杂函数中的潜力和挑战。

38. 论文《FLEX-LBP》提出了一种可学习的**局部二进制模式（LBP）**，通过反向传播自动优化纹理描述符参数，显著提升分类精度。

39. 论文《Consistent Video-to-Video Translation via Explicit Correspondences》引入 **vid2vid-long** 框架，通过显式帧间对应关系提升视频生成的长程时序一致性。

40. 论文《Goal Encoding in LLMs》通过因果干预证实了 LLM 内部存在**编码目标的神经表征**，并证明了其对任务执行的指导作用。

41. 论文《Metal Sandbox》为 **Apple Silicon** 上的 GPU 编程智能体提供隔离执行环境与命令调度，显著提升了任务吞吐量。

42. 论文《Negative-Only Policy Optimization for One-Sided Verifiable Rewards》提出 **NOPO 算法**，针对单侧可验证奖励机制，通过抑制负例实现策略优化。

43. 论文《Synthesis Smuggling》揭示了恶意 LLM 可能通过隐写术在输出中隐藏用户隐私信息的**侧信道攻击**威胁。

44. 论文《LiveGeo》发布了 **GeoWorld 平台与 LiveGeo 基准**，用于评估智能体在动态演化的地理环境中的决策能力。

45. 论文《Programming Quantum Circuit Parameters with Large Language Models》探讨了 LLM 直接生成**变分量子电路参数**的能力及其对物理结构信息的依赖。

46. 论文《Ballad》提出了一种基于**多臂老虎机的 LLM 路由算法**，根据任务难度动态选择模型，在降低 API 成本的同时维持启发式搜索质量。
